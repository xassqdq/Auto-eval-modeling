\subsection{组合赋权}

为克服单一赋权方法的局限性，本文将<< subjective_method >>（主观权重）与<< objective_method >>（客观权重）进行组合，以获得更为合理的综合权重。

<% if combination_method == "linear" %>
\subsubsection{线性加权组合}

线性组合权重为：
\begin{equation}
    w_j = \alpha \cdot w_j^{S} + (1 - \alpha) \cdot w_j^{O}
    \label{eq:comb_linear}
\end{equation}
其中 $\alpha = << alpha >>$ 为主观权重的偏好系数，$w_j^S$ 和 $w_j^O$ 分别为<< subjective_method >>和<< objective_method >>所得权重。

<% elif combination_method == "multiplicative" %>
\subsubsection{乘法归一化组合}

乘法组合权重为：
\begin{equation}
    w_j = \frac{w_j^S \cdot w_j^O}{\sum_{k=1}^{n} w_k^S \cdot w_k^O}
    \label{eq:comb_multiplicative}
\end{equation}

<% elif combination_method == "game_theory" %>
\subsubsection{基于博弈论的组合赋权}

博弈论组合赋权的核心思想是使组合权重与各方法所得权重的偏差最小。设 $L$ 种赋权方法所得权重向量为 $\{\mathbf{w}_l\}_{l=1}^{L}$，组合权重为：
\begin{equation}
    \mathbf{w}^* = \sum_{l=1}^{L} \alpha_l^* \mathbf{w}_l
\end{equation}
其中 $\alpha_l^*$ 通过最小化各权重向量与组合权重的离差得到：
\begin{equation}
    \min \sum_{l=1}^{L} \left\| \sum_{k=1}^{L} \alpha_k \mathbf{w}_k - \mathbf{w}_l \right\|^2
\end{equation}
